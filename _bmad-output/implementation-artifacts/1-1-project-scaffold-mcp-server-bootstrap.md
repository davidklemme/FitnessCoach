# Story 1.1: Project Scaffold & MCP Server Bootstrap

Status: ready-for-dev

## Story

As a developer,
I want a fully configured MCP server project that connects to Claude via stdio,
so that I have a working foundation to build all fitness coaching tools on.

## Acceptance Criteria

1. **Given** a fresh clone of the repository
   **When** I run `npm install && npm run build`
   **Then** `dist/index.js` is produced by tsup as a single bundled file
   **And** `.nvmrc` specifies Node v22 LTS

2. **Given** `.env` is configured with required values
   **When** the MCP server starts
   **Then** `src/config.ts` validates environment variables via zod and fails fast with clear messages if any are missing
   **And** the server connects to Claude via stdio transport within 5 seconds (NFR9)

3. **Given** the MCP server is registered in Claude's MCP config pointing to `dist/index.js`
   **When** Claude starts a session
   **Then** the server connects successfully with zero tools registered
   **And** `npm run test` executes vitest with no failures

### Technical Requirements

**Node.js:** v22 LTS required. better-sqlite3 is incompatible with v24. Enforce via `.nvmrc`.

**Package Manager:** npm. No workspaces needed (single package).

**Build:** tsup (esbuild-based). Single bundled output file `dist/index.js`. MCP config points here.

**Transport:** stdio only. No HTTP layer in MVP.

**tsconfig.json key settings:**
- `"strict": true`
- `"module": "NodeNext"`, `"moduleResolution": "NodeNext"`
- `"target": "ES2022"` (Node 22 supports it)
- `"outDir": "dist"` (though tsup handles actual build)
- `"skipLibCheck": true` (faster builds)

**tsup.config.ts:**
- Entry: `src/index.ts`
- Format: `["esm"]`
- `dts: false` (no declaration files needed — this is an application, not a library)
- `clean: true`
- `external: ["better-sqlite3"]` — native module, cannot be bundled

**drizzle.config.ts:**
- `schema: "./src/db/schema.ts"`
- `out: "./drizzle/migrations"`
- `dialect: "sqlite"`
- `dbCredentials: { url: process.env.DATABASE_URL || "./fitness-coach.db" }`

### MCP SDK Patterns

**Import paths (SDK v1.x):**
```typescript
import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
```

**Server initialization pattern:**
```typescript
const server = new McpServer({
  name: "fitness-coach",
  version: "1.0.0",
});

const transport = new StdioServerTransport();
await server.connect(transport);
```

**Tool registration pattern (for future stories):**
```typescript
server.tool(
  "tool_name",              // snake_case per architecture
  "Description for Claude",
  { param: z.string() },   // Zod schema for inputs
  async ({ param }) => {
    return {
      content: [{ type: "text", text: JSON.stringify(result) }],
    };
  }
);
```

**Error response pattern:**
```typescript
return {
  content: [{ type: "text", text: "Actionable error message" }],
  isError: true,
};
```

### Naming Conventions (from architecture)

- **Files:** `kebab-case.ts` — `get-current-plan.ts`, `exercise-library.ts`
- **Functions/variables:** `camelCase` — `getCurrentPlan`, `exerciseId`
- **Types/interfaces:** `PascalCase` — `SessionLog`, `ExerciseMetadata`
- **Constants:** `SCREAMING_SNAKE` — `MAX_PAIN_THRESHOLD`
- **Zod schemas:** `camelCase` + `Schema` suffix — `logSessionSchema`
- **MCP tool names:** `snake_case` — `get_current_plan`, `log_session`
- **DB tables:** `snake_case`, plural — `session_logs`, `exercises`
- **DB columns:** `snake_case` — `created_at`, `joint_stress_rating`
- **Test files:** Co-located — `src/tools/get-current-plan.test.ts`

### Config Validation (src/config.ts)

```typescript
// Pattern: dotenv load → zod parse → export typed config → fail fast
import "dotenv/config";
import { z } from "zod";

const envSchema = z.object({
  DATABASE_URL: z.string().min(1, "DATABASE_URL is required"),
  TRAINER_MD_PATH: z.string().min(1, "TRAINER_MD_PATH is required"),
});

const parsed = envSchema.safeParse(process.env);
if (!parsed.success) {
  console.error("Invalid environment configuration:");
  for (const issue of parsed.error.issues) {
    console.error(`  ${issue.path.join(".")}: ${issue.message}`);
  }
  process.exit(1);
}

export const config = parsed.data;
```
